# Ashen Halls

Ashen Halls is an original browser prototype inspired by old party-based tactical CRPGs: grid exploration, an eight-member company, a nearby town, placed encounters, turn-based tactical combat, magic, supplies, elixirs, use-based skill growth, generated loot, and save/load through the browser.

Open `index.html` in a browser to play.

Controls:

- Exploration: arrow keys, WASD, the N/W/E/S buttons, or click an adjacent tile.
- Combat: choose Move, Attack, Cast, Guard, Elixir, or Wait, then click a target tile or unit.
- F1 writes context help into the Chronicle.
- Save and Load use the browser's local storage.
