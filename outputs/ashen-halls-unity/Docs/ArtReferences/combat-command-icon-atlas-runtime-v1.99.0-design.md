# Combat command icon atlas v1.99.0

Deterministic project-local UI art generated by `Tools/BuildCombatCommandIconAtlas.ps1`.

## Design intent

- Exact 1280×1024 transparent RGBA atlas: five columns by four rows, 256 px per cell.
- Bold, unframed silhouettes keep the command subject large and readable when reduced to 34–72 px.
- A minimum 18 px transparent gutter prevents atlas bleed; the builder validates empty cell boundaries.
- Semantic accents stay consistent: teal for movement/precision, red for attack/danger, violet for magic/stealth, and gold for defense, items, skills, and committed actions.
- No text, watermarks, embedded button frames, or external source art.
