# Spell and skill names

Current naming pass: 28 spells and 14 martial skills. Names express class identity; descriptions retain plain mechanical guidance. Stable formula codes, skill IDs, costs, levels, effects and save data are unchanged. Existing name aliases remain supported by audio and visual presentation.

Recognizable names such as Fireball, Chain Lightning, Hallowed Circle and Abyssal Ascendance remain. These are display-name changes, not new powers or balance changes.
