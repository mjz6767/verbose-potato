Tester workarounds:
- If clicks seem ignored, try pressing Enter on muster or B to begin the current company.
- In combat, use 1-6 for actions and Space to wait.
- In exploration, hover map tiles to see what they are before stepping onto them.
- Press I for the Armory; press C to jump straight to spell reference.
- Use Beta Lab from the Muster screen to stress test combat, spell cards, enemy casters, hazards, and sound without walking the map first.
- In Beta Lab combat, use the toolbar above the formula panel to refill, reset, refresh hazards, spawn enemy casters, and run SFX checks.
- If the game opens to a blank or stale screen, close it fully and relaunch from the latest extracted zip folder.
- If a zip build behaves oddly, delete the extracted folder and extract the zip again into a clean folder.
